# EvidenceGuard AI

EvidenceGuard AI is an exploratory Arabic–Hebrew research project on evidence reliability, cited answers, and abstention. In a controlled synthetic evaluation, its deterministic V2 system produced 48/48 strictly cited Full answers with Oracle evidence and 13/48 with E5 Top-5 retrieval. A separate local LLM development screen reached 3/8, below its predefined 6/8 gate. These results are limited to the study dataset. Source code and raw evaluation materials remain private pending a separate publication review.
