# EvidenceGuard AI

Exploratory Arabic–Hebrew research on evidence reliability, cited answers, and abstention.

## Evaluation overview

| System / evidence setting | Observed result |
| --- | --- |
| Deterministic V2 with Oracle evidence | 48/48 strictly cited Full answers |
| Deterministic V2 with E5 Top-5 retrieval | 13/48 strictly cited Full answers |
| Local LLM development screen | 3/8; below the predefined 6/8 gate |

These results come from a controlled synthetic evaluation and are limited to the study dataset.
